A modern and responsive **Digital Clock & Stopwatch** built using **HTML, CSS, and Vanilla JavaScript**.

TimeCraft provides a real-time digital clock, a high-precision stopwatch with lap recording, keyboard shortcuts, and a beautiful Dark/Light mode interface—all in a clean, responsive design.

---

## 🌟 Features

- 🕒 Live Digital Clock
- 📅 Current Date Display
- ⏱ High Precision Stopwatch (Milliseconds)
- ▶️ Start Stopwatch
- ⏸ Pause Stopwatch
- 🔄 Reset Stopwatch
- 🏁 Unlimited Lap Recording
- 🌙 Dark Mode / ☀️ Light Mode
- ⌨️ Keyboard Shortcuts
- 📱 Fully Responsive Design
- 🎨 Modern Glassmorphism UI
- ⚡ Fast & Lightweight

---

## ⌨️ Keyboard Shortcuts

| Key | Action |
|------|--------|
| Space | Start / Pause |
| R | Reset Stopwatch |
| L | Record Lap |
